# P1002 NOIP 2002 普及组 过河卒

## 题目描述

棋盘上 $A$ 点有一个过河卒，需要走到目标 $B$ 点。卒行走的规则：可以向下、或者向右。同时在棋盘上 $C$ 点有一个对方的马，该马所在的点和所有跳跃一步可达的点称为对方马的控制点。因此称之为“马拦过河卒”。

棋盘用坐标表示，$A$ 点 $(0, 0)$、$B$ 点 $(n, m)$，同样马的位置坐标是需要给出的。
![[ipmwl52i.png]]

现在要求你计算出卒从 $A$ 点（不经过马的控制点）能够到达 $B$ 点的路径的条数，假设马的位置是固定不动的，并不是卒走一步马走一步。

## 输入格式

一行四个正整数，分别表示 $B$ 点坐标和马的坐标。

## 输出格式

一个整数，表示所有的路径条数。

## 输入输出样例 #1

### 输入 #1

```
6 6 3 3
```

### 输出 #1

```
6
```

## 说明/提示

对于 $100 \%$ 的数据，$1 \le n, m \le 20$，$0 \le$ 马的坐标 $\le 20$。

保证起点不是马的控制点。

**【题目来源】**

NOIP 2002 普及组第四题


# 解析

这道题主要是涉及了[[二维网格计数动态规划]] 这个知识点

设置一个`dpm`数组用于放置对应位置能否移动，`dp`数组用于存放整个网格。因为马不能走的位置涉及到 -2 所以防止越界要偏移 2。所以下标最大取到 22 所以长度为23

源代码
```cpp
// P1002 过河卒 
#include <bits/stdc++.h>
using namespace std;

int i, j; // 终点
int n, m; //马所在的点
bool dpm[23][23];
long long dp[23][23];
 
int main() {
	cin >> i >> j >> n >> m; 
	i += 2;
	j += 2;
	n += 2;
	m += 2;
	
	dp[2][2] = 1;
	
	dpm[n][m] = true;
	dpm[n + 2][m + 1] = true;
	dpm[n + 2][m - 1] = true;
	dpm[n + 1][m + 2] = true;
	dpm[n + 1][m - 2] = true;
	dpm[n - 2][m + 1] = true;
	dpm[n - 2][m - 1] = true;
	dpm[n - 1][m + 2] = true;
	dpm[n - 1][m - 2] = true;
	
	for (int a = 2; a <= i; a++) {
		for (int b = 2; b <= j; b++) {
			if (a == 2 && b == 2)
				continue;
			if (!dpm[a][b])
				dp[a][b] = dp[a - 1][b] + dp[a][b - 1];
		}
	}
	cout << dp[i][j];
	return 0;
}
```
