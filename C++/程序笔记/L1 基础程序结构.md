# 一、 C++ 基础结构
```cpp
#include <iostream>
using namespace std;

int main() {
	return 0;
}
```

## 单词解释

`include` 包含
`using` 使用
`namespace`命名空间
`std`标准
`main`主要
`return`返回
`int`整型（整数）

## 结构含义
```cpp
#include <iostream> //导入 iostream 这个头文件
using namespace std;  // 使用标准命名空间

int main() {  //程序入口
				//未来写代码的地方
	return 0;  //程序结束
}
```


# 二、 变量和赋值

## 变量类型

| 数据类型 | 关键字         | 字节   | 取值范围               |
| ---- | ----------- | ---- | ------------------ |
| 整数   | `int`       | 4 字节 | \(10^{9}\)数量级      |
| 长整型  | `long long` | 8 字节 | \(10^{18}\)数量级     |
| 浮点数  | `double`    | 8 字节 | 有效小数 \(15 - 16\) 位 |

## 变量

- 定义：**在内存中取一个空间存放一些对应类型的数据**
- 命名规则：
  1、只能包含字母(\(A - Z\) 或 \(a - z\))、数字(\(0 - 9\)) 和下划线
  2、不能以数字开头，如 `2a` 就不合法
  3、不能以关键字作为变量名，如 `int`、`return` 就不合法
## 赋值
使用`=`来对变量进行赋值。语法为`类型 变量名 = 值;`

```cpp
int a = 100;
double pi = 3.1415926;
long long b = 9999999999
```

# 基本输入 & 输出

## 输出

使用`cout`进行输出。

实例代码（Playground/L1/cout.cpp）：

```cpp
#include <iostream>  // iostream 是 cout 必备的头文件
using namespace std;

int main() {
	cout << "Hello C++";  // 有双引号包裹的为字符串
	return 0;
}
```

以上代码输出 `Hello C++`
