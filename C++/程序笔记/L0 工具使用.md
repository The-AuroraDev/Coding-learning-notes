下面是两个脚本，都使用 `-std=c++14 -O2 -Wl,--stack=1073741824` 编译选项（其中 `-Wl,--stack=...` 只在 Windows 上的 MinGW 链接器里生效，Linux/macOS 上会自动忽略），输出文件名与源文件名相同（Windows 下为 `.exe`）。

---

## 1. `build.sh`（Linux / macOS / MSYS2 / Cygwin）


使用：

```bash
chmod +x build.sh
./build.sh main.cpp          # 生成 ./main （Windows 下生成 main.exe）
./build.sh                   # 编译当前目录所有 .cpp
```

---

## 2. `build.ps1`（Windows PowerShell）

使用：

```powershell
.\build.ps1 main.cpp        # 生成 main.exe
.\build.ps1                 # 编译当前目录所有 .cpp
```

若被执行策略拦截，用：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 main.cpp
```

---

## 说明与注意事项

| 项目 | 说明 |
|---|---|
| 输入 | `.cpp` / `.cc` / `.cxx` / `.c++` 源文件，可一次传多个；不传参数时编译当前目录全部 `.cpp` |
| 输出 | `hello.cpp` → `hello`（Linux/macOS）或 `hello.exe`（Windows），与源文件同目录 |
| `-Wl,--stack=1073741824` | 把栈设为 1 GB。**只有 Windows 的 MinGW 链接器支持**，`build.sh` 已在 Linux/macOS 上自动省略，否则 `ld` 会报 `unrecognized option '--stack'` |
| 编译器 | 默认 `g++`，可用环境变量 `CXX` 覆盖（如 `CXX=clang++`）；PowerShell 中为 `$env:CXX = "..."` |
| 退出码 | 全部成功返回 `0`，任一失败返回 `1`，便于接入 CI |
| 带空格路径 | 两个脚本都对路径做了引号/数组参数处理，可安全编译含空格的路径 |
