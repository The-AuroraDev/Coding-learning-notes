# 向上、向下取整和四舍五入

使用`cmath`包中的`seil()`函数进行向上取整、`floor()`函数进行向下取整、`round`函数进行四舍五入（用的不多）

```cpp
#include <iostream>
#include <cmath>
using namespace std;
int main() {
	double pi = 3.1415926535;
	cout << seil(pi) << "\n"; // 输出4
	cout << floor(pi) << "\n"; // 输出3
	cout << round(pi) << "\n"; // 输出3
	return 0;
}
```
