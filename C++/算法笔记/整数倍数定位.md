# 整数倍数定位笔记：向下取整与向上取整

设 \(x>0\)，\(n\) 为整数。

## 1. 向下取整形式

\[
\left\lfloor \frac{n}{x}\right\rfloor x
\]

含义：**不超过 \(n\) 的最大 \(x\) 的倍数**。  
也就是“从 \(n\) 往小方向找，离 \(n\) 最近的 \(x\) 的倍数”，且包含 \(n\) 本身。

等价写法：

\[
\left\lfloor \frac{n}{x}\right\rfloor x = n-(n\bmod x)
\]

例：

\[
n=10,x=3 \Rightarrow \left\lfloor \frac{10}{3}\right\rfloor 3=3\cdot3=9
\]

\[
n=9,x=3 \Rightarrow \left\lfloor \frac{9}{3}\right\rfloor 3=9
\]

---

## 2. 向上取整再减 \(x\) 形式

\[
\left\lceil \frac{n}{x}\right\rceil x-x
\]

含义：**严格小于 \(n\) 的最大 \(x\) 的倍数**。  
若 \(n\) 本身是 \(x\) 的倍数，则会再往前退一个 \(x\)。

等价写法（\(n\) 为整数时）：

\[
\left\lceil \frac{n}{x}\right\rceil x-x
=
\left\lfloor \frac{n-1}{x}\right\rfloor x
\]

例：

\[
n=10,x=3 \Rightarrow \left\lceil \frac{10}{3}\right\rceil3-3=4\cdot3-3=9
\]

\[
n=9,x=3 \Rightarrow \left\lceil \frac{9}{3}\right\rceil3-3=3\cdot3-3=6
\]

---

## 3. 对比记忆

| 表达式                                         | 含义                                 |
| ------------------------------------------- | ---------------------------------- |
| \(\left\lfloor \frac{n}{x}\right\rfloor x\) | 不超过 \(n\) 的最大 \(x\) 的倍数，包含 \(n\)   |
| \(\left\lceil \frac{n}{x}\right\rceil x-x\) | 严格小于 \(n\) 的最大 \(x\) 的倍数，不包含 \(n\) |

---

## 4. 易错点纠正

- 不是“距离 \(x\) 最近”，而应说：**距离 \(n\) 最近的、在某一侧的 \(x\) 的倍数**。
- 不是“小于 \(x\) 的 \(x\) 的倍数”，而应说：  
- **不超过 \(n\) 的 \(x\) 的倍数**；
-  或 **严格小于 \(n\) 的 \(x\) 的倍数**。
- 前提通常是 \(x>0\)。编程中若涉及负数，整数除法、取模行为要额外注意。
