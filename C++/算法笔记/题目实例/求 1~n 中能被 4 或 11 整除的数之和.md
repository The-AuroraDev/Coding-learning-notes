
## 1. 题目
求 $1\sim n$ 中，所有能被 $4$ 或 $11$ 整除的数字之和。

## 2. 核心思想
使用**容斥原理**：
$$
\text{答案}
=
\text{能被4整除的数之和}
+
\text{能被11整除的数之和}
-
\text{能被44整除的数之和}
$$

原因：同时能被 $4$ 和 $11$ 整除的数，就是能被
\[
\operatorname{lcm}(4,11)=44
\]

整除的数，这部分会被重复计算，所以要减去。

---

## 3. 求 1~n 中能被 m 整除的数之和
设：

$$
k=\left\lfloor \frac{n}{m} \right\rfloor
$$

则这些数为：

$$
m,2m,3m,\dots,km
$$

它们的和为：

$$
m(1+2+\cdots+k)
=
m\cdot \frac{k(k+1)}{2}
$$

记：

$$
S(m)=m\cdot \frac{k(k+1)}{2},
\quad
k=\left\lfloor \frac{n}{m} \right\rfloor
$$

---

## 4. 最终公式

$$
\text{ans}=S(4)+S(11)-S(44)
$$

其中：

$$
S(m)=m\cdot \frac{k(k+1)}{2},
\quad
k=\left\lfloor \frac{n}{m} \right\rfloor
$$

---

## 5. C++ 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

// 求 1~n 中所有能被 m 整除的数之和
ll sumDivisible(ll n, ll m) {
    ll k = n / m;
    return m * k * (k + 1) / 2;
}

int main() {
    ll n;
    cin >> n;

    ll ans = sumDivisible(n, 4)
           + sumDivisible(n, 11)
           - sumDivisible(n, 44);

    cout << ans << endl;
    return 0;
}
```

---

## 6. 复杂度

- 时间复杂度：$O(1)$
- 空间复杂度：$O(1)$

---

## 7. 易错点

1. 不要忘记减去能被$44$ 整除的部分。
2. $44=\operatorname{lcm}(4,11)$，不是 $4\times 11$本身这个结论要理解。
3. $n$ 可能较大，答案可能超过 `int`，建议使用 `long long`。
4. 计算：

   $$
   m\cdot \frac{k(k+1)}{2}
   $$

   时，先乘后除也可以，但要注意数据范围；用 `long long` 更安全。

---

## 8. 一句话总结

用容斥原理：

$$
S(4)+S(11)-S(44)
$$

每个 \(S(m)\) 用等差数列求和公式：

$$
S(m)=m\cdot \frac{k(k+1)}{2},
\quad
k=\left\lfloor \frac{n}{m} \right\rfloor
$$

即可在 $O(1)$ 时间内求出答案。
