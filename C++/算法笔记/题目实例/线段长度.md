# 线段长度

## 题目描述

已知线段的两个端点坐标分别为：

- \(A(X_a, Y_a)\)
- \(B(X_b, Y_b)\)

求线段 \(AB\) 的长度，结果保留到小数点后 \(3\) 位。

## 输入格式

第一行是两个小数 \(X_a, Y_a\)，即点 \(A\) 的坐标。

第二行是两个小数 \(X_b, Y_b\)，即点 \(B\) 的坐标。

输入中所有实数的绝对值均不超过 \(10000\)。

## 输出格式

输出一个实数，即线段 \(AB\) 的长度，保留到小数点后 \(3\) 位。

## 输入输出样例

### 输入数据 1

```text
1 1
2 2
```

### 输出数据 1

```text
1.414
```


# 解答

![[线段距离.png]]

由图：

我们可以把线段 \(AB\) 看作是直角三角形的斜边。
1. **水平直角边**：从点 \(A(x_a, y_a)\) 到点 \(B(x_b, y_b)\) 在 \(x\) 轴方向上的位移，长度为 \(|x_b - x_a|\)（图中标注为 `xb - xa`）。
2. **竖直直角边**：从点 \(A(x_a, y_a)\) 到点 \(B(x_b, y_b)\) 在 \(y\) 轴方向上的位移，长度为 \(|y_b - y_a|\)（图中标注为 `yb - ya`）。

根据**勾股定理**（\(c^2 = a^2 + b^2\)），斜边 \(AB\) 的长度计算公式为：
\[
 AB = \sqrt{(x_b - x_a)^2 + (y_b - y_a)^2} 
\]

---

### C++ 解法
```cpp
#include <iostream>
#include <cmath>
#include <iomanip>
using namespace std;

int main() {
    double xa, ya, xb, yb;
    cin >> xa >> ya;
    cin >> xb >> yb;
    
    // 计算距离
    double distance = sqrt(pow(xb - xa, 2) + pow(yb - ya, 2));
    
    // 保留3位小数输出
    cout << fixed << setprecision(3) << distance << endl;
    
    return 0;
}
```
