# 术语表（Bubble Tea & Cobra）

供阅读本目录第三方教程中文版时参考。英文术语均保留原名，便于对照官方文档。

## Bubble Tea 术语

| 英文 | 中文 | 说明 |
|------|------|------|
| Elm Architecture | Elm 架构 | Bubble Tea 借鉴的函数式 UI 范式：Model + Update + View |
| Model | 模型 | 保存应用状态的类型（通常是 struct） |
| Init | 初始化 | 程序启动时运行的方法，返回初始 `Cmd` |
| Update | 更新 | 处理事件（消息）并改变模型的方法 |
| View | 视图 | 根据模型渲染 UI 的方法 |
| Cmd | 命令 | 一个 `func() Msg`，用来执行 I/O 并返回消息 |
| Msg | 消息 | 程序内部传递的事件/结果，可任意类型 |
| KeyPressMsg | 按键消息 | 用户按键时自动产生的消息 |
| tea.Quit | 退出指令 | 特殊命令，让运行时退出程序 |
| tea.NewProgram | 创建程序 | 用初始模型创建并运行 Bubble Tea 程序 |
| tea.NewView | 创建视图 | 用字符串构造一个 `tea.View` |
| WindowTitle | 窗口标题 | 可选，设置终端窗口标题 |

## Cobra 术语

| 英文 | 中文 | 说明 |
|------|------|------|
| rootCmd | 根命令 | 整个 CLI 应用的顶层命令 |
| subcommand | 子命令 | 挂在某个命令下的下级命令 |
| PersistentFlags | 持久标志 | 对命令及其所有子命令都生效的 flag |
| Local Flags | 本地标志 | 只对当前命令生效的 flag |
| Run | 运行函数 | 命令真正执行时调用的处理函数（不返回错误） |
| RunE | 运行函数（带错误） | 同 Run，但可返回 `error` |
| Execute() | 执行入口 | 启动命令解析与执行的函数 |
| MarkFlagRequired | 标记必填 | 把某个 flag 设为必须提供 |
| Flag Groups | 标志组 | 一组 flag 的约束（同时必填 / 互斥 / 至少其一） |
| TraverseChildren | 遍历子命令 | 让父命令的本地 flag 也被解析的开关 |
| viper | 配置库 | Cobra 官方配套的配置管理第三方库 |
| Args | 参数校验 | 对位置参数（非 flag）的校验字段 |

## 通用 Go 术语

| 英文 | 中文 | 说明 |
|------|------|------|
| goroutine | 协程 | Go 的轻量级并发单元；Bubble Tea 的命令在内部用 goroutine 异步运行 |
| struct | 结构体 | Go 的复合类型，常用来定义 Model |
| interface | 接口 | 如 `error` 接口，Bubble Tea 的消息可实现它 |
