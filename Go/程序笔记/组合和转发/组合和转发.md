# 组合和转发

## 组合

代码：Playground/组合和转发/compose.go
相当于在 `struct` 里面使用另一个 `struct`

## 嵌入

代码：Playground/组合和转发/embed.go
```go
type Temperature struct {
	high, low float64
}

func (t Temperature) Average() float64 {
	return (t.high + t.low) / 2
}

type location struct {
	lat, long float64
}

type report struct {
	sol         int
	Temperature   // 转发
	location
}
```

-  **转发时结构会自动给被嵌入的类型生成同名字的字段。**
-  转发可以让我们有有两种访问的结构体内字段的方法：
```go
fmt.Println(chengDuReport.high)  // 20
fmt.Println(chengDuReport.Temperature.high) // 20  与与上一条等价（使用了转发）
```

## 命名冲突

代码：Playground/组合和转发/collision.go
如果你对两个转发的类型定义了一个同样的名字，在调用到它的时候编译器就会报错。但是如果你是使用的完整的调用就是可以的。
```go
type sol int

type Temperature struct {
	high, low float64
}

func (t Temperature) Average() float64 {
	return (t.high + t.low) / 2
}

type location struct {
	lat, long float64
}

type report struct {
	sol
	Temperature   
	location
}
func (s sol) days() int {
	//....
	return 1
}

func (l location) days() int {
	// ....
	return 2
}

func main() {
	chengDuTemperature := Temperature{high: 20, low: 10}
	chengDuLocation := location{30.65, 104.06}
	chengDuReport := report{sol: 15, Temperature: chengDuTemperature, location: chengDuLocation}

	fmt.Println(chengDuReport.days())  // Error 命名冲突(./collision.go:39:28: ambiguous selector chengDuReport.days)
	fmt.Println(chengDuReport.location.days())   // 没有问题 2
}
```
