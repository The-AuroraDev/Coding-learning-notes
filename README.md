## 这是什么

存放我在学习 **C++ 算法**和 **Golang 开发**过程中的笔记与代码片段。以中文为主，注重可运行、可查阅，不追求教材式的完备。

## 目录结构

```
.
├── C++/
│   ├── Playground/      # 构建与实验脚本
│   └── 算法笔记/
├── Go/
│   ├── Playground/      # 基础框架与实验代码
│   ├── 程序笔记/         # 核心概念与实战
│   └── 第三方笔记/       # 生态、库与工具
├── CONTRIBUTING.md
├── LICENSE
└── README.md
```

## 如何使用

- 按目录找到主题，直接读代码和要点
- clone 下来修改 `Playground/` 里的示例自行练习
- 发现错误或缺失，按 [CONTRIBUTING.md](CONTRIBUTING.md) 提 PR
